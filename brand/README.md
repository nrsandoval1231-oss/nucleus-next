# OBELISK — Brand Assets v1.0

Canonical product name: **OBELISK** (formerly Nucleus Next).
Brand direction: **The Continuum** — two asymmetric architectural pillars linked by a flowing negative-space channel.

Tagline: **Intelligence in Context.**
Experience: **The Living Present** — Everything in context. Nothing out of sight.

This directory contains the first editable implementation of the selected visual identity. The geometry is a draft vector interpretation, not an exact trace of the approved concept image; owner approval and trademark clearance remain outstanding.

## Assets
- `logos/continuum-symbol-gold.svg`: scalable signature mark
- `tokens/colors.json`: palette, typography and radii
- `tokens/obelisk.css`: CSS design tokens
- `BRAND-GUIDELINES.md`: usage and implementation rules

Source package includes additional PNG sizes and lockups, which should be imported after binary-asset upload is available.
